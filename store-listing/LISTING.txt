Description *   (paste into the Description box)

Shohoz Ticket Cutter helps you book Bangladesh Railway e-tickets on train.shohoz.com without hunting through the seat map by hand.

Set From, To, Date of Journey, Class, Train and how many seats you need (1–4). Press Start cutter. The extension searches, opens your train, and selects seats that sit together on the same side of the aisle in the same coach. When the OTP page appears, the bot stops so you can enter the code and pay yourself.

WHY INSTALL
• Adjacent seats for family or friends — not scattered across the aisle or across coaches
• Middle-of-coach seats when a bogie still has plenty of space
• If a coach is filling up, it takes any side-by-side block and only uses the last rows as a last resort
• Optional preferred coach (for example KHA or GHA)
• Optional retry until seats appear
• Live status in the popup and on the page

HOW TO USE
1. Install the extension and pin it.
2. Log in to https://train.shohoz.com
3. Open Shohoz Ticket Cutter.
4. Choose From, To, Date, Class, Train and seat count.
5. Press Start cutter and keep the tab open.
6. When OTP appears, the job is done — enter OTP and complete payment.

SEAT RULES
• 2 seats: a same-row pair such as GHA-33 and GHA-34
• 4 seats: two consecutive rows on one side, such as 29, 30, 33, 34 or 31, 32, 35, 36
• Seats always stay in one coach
• You still confirm purchase and enter OTP yourself

NOTES
This extension is an independent helper for the official Bangladesh Railway / Shohoz e-ticketing site. It is not affiliated with Shohoz, Bangladesh Railway, or BRITS. You must already have a valid account, stay logged in, and follow the website’s terms. Use it only for your own tickets.

Single purpose
  Helps the user search trains and select adjacent seats on Bangladesh Railway e-ticketing (train.shohoz.com), then stops at the OTP page.

Does this extension collect or use user data?
  Yes — only on the device.

Data used
  • Trip preferences you type (From, To, date, class, train, seat count, coach)
  • Live status logs while the cutter is running
  Stored with chrome.storage on your computer. Not sent to the developer. Not sold. No analytics.

Remote code
  No

Host permission justification
  https://train.shohoz.com/* and https://eticket.railway.gov.bd/*
  Required to read the booking page and click search, train, seats and Continue Purchase for the user.

tabs / scripting / storage justification
  tabs — open or focus the Shohoz tab
  scripting — run the cutter on that tab
  storage — remember your last trip and status
